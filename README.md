# lab-fixes — находки вычитки лаб

## Папки

| Папка | Что внутри |
|---|---|
| `backend/` | бэкенд: php-coffee (ООП), php, postgresql, redis, rabbitmq, laravel, nestjs, graphql |
| `devops/` | docker, traefik, kubernetes |
| `frontend/` | js, vue, typescript, nuxt, angular, css, tailwind |
| `common/` | всё общее: порядок лаб, инструкция вычитки, вопросы по сайту, скрипты |

## Файлы

| Файл | Что значит |
|---|---|
| `<лаба>.md` | находки вычитки одной лабы и принятые решения (`[x]` — выбранный вариант) |
| `_chain_<направление>.md` | стыки между лабами направления: что одна берёт у другой |
| `common/_order.md` | порядок прохождения и зависимости между лабами |
| `common/_proofread.md` | статус вычитки каждой лабы + инструкция, как вычитывать |
| `common/site.md` | общие вопросы по сайту и версиям (Postgres, Node и т.п.) |
| `common/_tools/prep.py` | нарезает методичку на куски для вычитки |
