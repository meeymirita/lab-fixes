## Сайт и инструменты

- **Картинки:** WebP-превью 1200 px (`works/images/thumbs/<лаба>.webp`, ~250 КБ), оригинальный PNG грузится только в лайтбоксе — главная весит ~3,4 МБ вместо ~34 МБ.
- **Карточки на главной** (`index.html`, массив `projects`): у каждой есть сноска `note:` «что требуется» (Docker, аккаунт, домен, ключи, «Production Hell» — решаете сами); отрисовывается как `* …`. `check-site.py` следит, чтобы сноска была у всех.
- **Страницы:** `works/<лаба>.html` (витрины), `works/progress.html` (прогресс, сворачивание, статусы), `works/verification.html` (то же, что `_verification.md`), `works/changelog.html`.
- **Скрипты:** `tools/check-site.py` (сверка реестров), `tools/build-progress.py`, `tools/build-verification.py`, `tools/patch-manuals.py` (кнопка «Все работы» и защита от мигания поиска), `tools/restore-symbols.py` (возвращает пропавшие символы), `tools/save-push.sh`. После перевыгрузки методички из дизайн-исходников запускать `patch-manuals.py` и `restore-symbols.py`.
- **Методички — «бандлы»:** текст лежит в сжатом JSON внутри HTML. Читать и править через `fixes/common/_tools/bundle.py` (`dump` / `grep` / `sub`; из Python — `jsub(path, [(старое, новое, мин)], unit=ключ_шага)` — замена по строкам внутри JSON без возни с экранированием, сначала проверка, потом запись). `jre` — то же по регулярным выражениям (нужен для кода с выравниванием пробелами). Поле `text` (плоский текст, схлопнутые пробелы) обновляется только если замена однострочная; видимый текст — поле `html`, поэтому результат правки всегда проверять в браузере.

- **Консоль методичек:** ошибка `reading 'done'` (рантайм вызывал `componentDidUpdate` без prevState) исправлена 04.10 патчем шаблона в `tools/patch-manuals.py`; вместе с ней заработали прокрутка наверх после «дальше →» и сохранение прогресса при смене состояния.

Исправлено `restore-symbols.py` (≈150 вставок по 19 лабам); новые лабы (Perf, Algo) символы не теряли. Если блоки кода извлекаются в JSON из методичек, символы могут пропадать снова — сверять с HTML.
- **Врезки с акцентным фоном** были нечитаемы — исправлено CSS-правилом в шаблоне каждой методички (`bundle.patch_template`).
