# Допущения и подмены при проверках

Вынесено из `CLAUDE.md` 05.10.2026.


«Проверено» означает: блоки методички собраны и запущены на моих стендах, результат сверен с текстом. Но стенды отличались, и это нужно помнить, если студент сообщит о проблеме, которую я «не видел»:

1. **Стенды — вне репозитория** (scratchpad), порты и сети мои, а не из методичек: Laravel API `:8100`, Vite `:5273`, Reverb `:8180`, Postgres `:5433`, Redis `:6380`, Mailpit `:8125`; Perf — nginx `:8080`, Octane `:8081`, контейнеры с лимитами CPU (отдельный override, ноутбук греется); Inertia — `artisan serve :8200`; NestJS/GraphQL — сети `nsnet`/`gqnet`, два инстанса GraphQL запускались `docker run`, а не compose. В методичках порты стандартные (3000, 5173, 8000, 8080…) — конфликты у студента возможны.
2. **Блоки кода извлекались из методичек в JSON** (`*_blocks.json`): символы ✅ ☰ эмодзи терялись (сверять с HTML), многофайловые блоки приходилось резать по строкам-заголовкам `// путь`, файл `package.json` с первой строкой-комментарием `// packages/…` невалиден как JSON (студент так не скопирует), блоки-«патчи» («добавить», «заменить») применял вручную. «Собрал по блокам» ≠ «скопировал дословно».
3. **Часть фронта писал сам по описанию:** Tailwind — три страницы Pulse собраны руками (иконки карточек — эмодзи, «☰» вставлен); Laravel 6.3 — Vue-доска написана вручную без `create-vue`, добавлен маршрут `GET /api/v1/workspaces` (в тексте «допишите сами»); TypeScript — веб-пакет через `npm create vue@latest web -- --ts --pinia` без интерактивных вопросов (получает Vite 8, не 7); Nuxt hydration проверялся в **dev** (в prod предупреждений нет).
4. **CSS:** мой первый «итоговый» сайт содержал все «❌»-блоки подряд (перебивали ✅); потом собрал чистый итог и варианты «сломано/починено» отдельными копиями. Шаг 3.2 воспроизводится только на состоянии «как на 3.2» (без правил 5.2).
5. **PostgreSQL:** все блоки шага — одним сеансом `psql` с `\pset null '∅'` (без `.psqlrc`); `\watch` пропущен; блоки «[A]/[B]» — отдельным двухсеансовым скриптом; таблицы «ожидаемого вывода» сверялись построчно, сокращённые блоки с «…» — нет.
6. **Правки методичек проверены на моём стенде, где ту же правку делал я руками;** полный повторный проход «как студент по исправленному тексту» сделан не везде (особенно TypeScript: 9 правок и новая точка входа `@warehouse/core/browser`; Nuxt: `RecentlyViewed.vue`). Поле `text` в бандле (плоский текст для поиска) при многострочных заменах `jsub` не обновляется — поиск по сайту может показывать старую формулировку.
7. **Не воспроизводилось в браузере:** замедление `usePoll` в скрытой вкладке (Inertia 5.4 — по исходникам). **Не запускалось:** workflow GitHub Actions (Perf 9.2), Blackfire, Let's Encrypt, задания «Production Hell».
8. **Платформа:** macOS arm64 → Docker `linux/arm64` (поэтому в `node:24-slim` падал `npm ci` с `better-sqlite3` — нет готового бинарника; на amd64 могло бы работать); числа производительности (k6, `ab`, размеры бандлов) — с моего ноутбука, в текстах это «≈»; Zod 4, Vitest 5, Express 5.2, Vite 7/8 — актуальные на 04.10.2026 версии (потом могут уйти).
9. **Состояние стендов:** хранились в `/private/tmp/claude-501/…/scratchpad/` — это временная папка, после очистки пропадёт (пересобирать по методичке; Docker на Mac очищен 05.10.2026 — образов и томов нет).
10. **Docker Lab (13.10.2026):** блоки выполнялись не в Docker Desktop владельца, а в изолированном `docker:dind` (чтобы чужие контейнеры не попадали в выводы): статусы вида `Up Less than a second` и порядок строк `pull` отличаются от живого терминала; выводы `docker pull` очищены от промежуточных стадий; `localhost` из инструментального контейнера ведёт к демону через `~/.curlrc` (`connect-to`), поэтому порты, опубликованные на `127.0.0.1` (Adminer), из контейнера не видны (проверка через `docker compose exec`); `docker version`/`docker info` в шаге 1.3 сняты с настоящего Mac; интерактивные команды (`-it`, `watch` в отдельном окне) показаны без терминала; файлы bind mount принадлежат root внутри тестового стенда, на Mac Docker Desktop подгоняет владельца под пользователя. Не запускались: GHCR/токен, workflow на GitHub, `--platform`.


## Traefik Lab (18.10.2026)
- Стенд — Docker-в-Docker (`traefik-dind`) на Docker Desktop; клиент (`curl`, `psql`, `dig`, `k6`) — контейнер-терминал на Alpine, а не Mac: имена `*.localhost` подставляются через `--connect-to` и `/etc/hosts` (в `curl` на Mac они разрешаются сами); корень `mkcert` копируется в системное хранилище контейнера в начале каждой сессии (на Mac его ставит `mkcert -install` один раз).
- «Программа на хосте» в шаге 9.1 — контейнер с `--network host` (на Mac — `python3 -m http.server`); `host.docker.internal` — через `host-gateway`.
- ACME (8.2–8.7) — Pebble и `challtestsrv`, а не Let’s Encrypt; DNS-01 — адаптер `exec`; права на `acme.json` проверены на Linux-файловой системе (на Mac могут не срабатывать).
- Адреса клиентов (`X-Forwarded-For`, `RemoteAddr`) — адреса контейнера-терминала в сети Docker, на Mac это адрес шлюза виртуальной машины.
- Тяжёлые образы (Grafana, Jaeger, Prometheus) запускались один раз и удалены вместе со стендом.
