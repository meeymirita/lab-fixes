- размер дампа (цель ≤ 30 МБ, иначе — вне Git).

**Prisma 7**
- генератор `prisma-client`: импорты `./generated/prisma/client.js`, расширения `.js`, `moduleFormat` по умолчанию; `prisma.config.ts` (`dotenv/config`);
- `relationLoadStrategy: 'join'` требует `previewFeatures = ["relationJoins"]` (в документации — Preview);
- TypedSQL: путь импорта `./generated/prisma/sql/index.js`, `-- @param`, `prisma generate --sql`;
- `relationMode = "prisma"` и поведение `migrate dev --create-only` («Already in sync») при ручных индексах, `EXCLUDE`, генерируемых колонках, `CHECK`, триггерах — Prisma не должна пытаться их удалить;
- `Unsupported("tstzrange")?` у генерируемой колонки `period`, колонка `phone_norm` (генерируемая) — поведение клиента при `create`;
- код и класс ошибки при нарушении `EXCLUDE` (`23P01`) и триггера (`23514`) через адаптер `pg` — `isOverlapViolation` написана по тексту и `meta` (13.4);

- `$transaction([set_config, query(args)])` в расширении `query` (16.4): тип `query(args)`, поведение во вложенных запросах; `$on('query')` на расширенном клиенте;
