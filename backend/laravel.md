Находки (исправлено в методичке):
- **[тех] 1.1, `.env`: `REVERB_HOST=localhost`** — воркер очереди в Docker публикует событие на `localhost:8080` (внутри контейнера там ничего нет): `Pusher error: cURL error 7`, job `TaskAssigned` падает → `REVERB_HOST=reverb`.
- **[тех] 1.1/6.1, `SANCTUM_STATEFUL_DOMAINS`** — в `config/sanctum.php` по умолчанию нет `localhost:5173` (методичка говорит «уже настроено»): вход с Origin `http://localhost:5173` даёт 500 «Session store not set on request» → в `.env` добавлено `SANCTUM_STATEFUL_DOMAINS=localhost,localhost:5173`.
- **[тех] 4.3, `withExceptions`** — Laravel превращает `AuthorizationException` в `AccessDeniedHttpException` до вызова колбэков, поэтому первый колбэк «мёртв», а общий `Throwable`-fallback отвечал 500 на любой 403 и «съедал» ответ `->response()` лимитера (429 → 500) → ловим `AccessDeniedHttpException`, статус берём из `HttpExceptionInterface`, `HttpResponseException` отдаём как есть; уточнено, что при `APP_DEBUG=true` fallback возвращает `null` (стандартный отладочный JSON).
- **[тех] 6.2, `$this->authorize()`** — в базовом `Controller` Laravel 13 нет трейта `AuthorizesRequests`: `Call to undefined method authorize()` → добавить трейт или `Gate::authorize`.
- **[тех] 6.2, `authorize('create', $project)`** — политика выбирается по классу первого аргумента (ищется `ProjectPolicy`, где `create(User)` возвращает `false`): создавать задачи не может никто (403) → `authorize('create', [Task::class, $project])` (тогда срабатывает `TaskPolicy::create(User, Project)`); в 6.4 добавлена недостающая `WorkspacePolicy::invite`.
- **[тех] 4.1, `store()`** — `$project->tasks()->create(...)`: значения по умолчанию из БД не попадают в модель, `status` равен `null`, и `TaskResource` падает на `->status->value` (500) → `$task->refresh()->load(...)` (и ответ остаётся 201, как ждёт тест `assertCreated`).
- **[тех] 2.7, `Activity`** — `public $timestamps = false` при миграции с `timestamps()`: `created_at` всегда `NULL`, `Activity::latest()->first()` возвращает случайную запись → строка убрана.
- **[тех] 9.4, `ShouldBroadcastAfterCommit`** — такого интерфейса в Laravel нет (`Interface … not found`, отправка назначения падает 500) → `implements ShouldBroadcast, ShouldDispatchAfterCommit`.
- **[тех] 7.1, эксперимент с активностью** — в консоли нет залогиненного пользователя, `ActivityLogger` резолвится в `NullActivityLogger`, записей нет, и `->first()->only()` падает на `null` → добавлено `Auth::login(User::first())`.
- **[текст] 5.1** — `TaskNotifier` ещё не существует, ошибка называется «Target class … does not exist», а не «is not instantiable» → пояснено (создать пустой интерфейс).
- **[текст] 8.2** — `install:api` таблицу `notifications` не создаёт → поправлен комментарий. **9.1** — кеш лежит в БД Redis №1 (`-n 1`), префикс `laravel-database-laravel-cache-…` (дефисы). **1.2** — 21 таблица с `migrations`.
